# SETTLEMATE

Your New City. Your New Home. Everything in One Place.

A location-based service discovery website for students and professionals moving to a new city in India.
Built with HTML5, CSS3 and vanilla JavaScript (no frameworks).

## Run locally
1. Install Visual Studio Code and the **Live Server** extension (Ritwick Dey).
2. Open this folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server** (opens at http://127.0.0.1:5500).

An internet connection is needed for map tiles, icons and fonts.

## Project structure
- `index.html` – page structure
- `style.css` – styles and responsive layout
- `script.js` – data, search, filters, map, booking, login, profile
- `assets/icons` – logo and favicon

## Important
This is a frontend academic prototype. All listings, ratings and verified badges are sample data.
Login and bookings are demonstrations stored in the browser (localStorage). No payments are processed
and the emergency page does not dispatch help; verify all numbers independently.
